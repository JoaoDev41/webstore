# 🛒 WebStore

Interface de e-commerce desenvolvida com HTML, CSS e JavaScript, com foco em uma experiência moderna, responsiva e visualmente atrativa.

O projeto utiliza GSAP e seus recursos de animação para criar uma navegação dinâmica e destacar diferentes elementos da interface.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- ScrollSmoother
- SplitText

## ✨ Destaques do projeto

- Interface inspirada em e-commerce
- Layout responsivo
- Animações com GSAP
- Elementos animados durante a rolagem
- Rolagem suave com ScrollSmoother
- Animações de textos com SplitText
- Interações desenvolvidas em JavaScript
- Experiência visual moderna

## 🎯 Objetivo

O objetivo deste projeto foi desenvolver uma experiência de e-commerce moderna, explorando conceitos de UI/UX, responsividade, interatividade e animações avançadas no Front-End.
